05 classes implementacao.puml   -> png/05 classes implementacao.png
   DIAGRAMA DE CLASSES DE IMPLEMENTAÇÃO (visão de código): classes, campos e
   assinaturas completas prontas para virar Rust.
     main (bin)          -> papel_de(args) / construir(papel, cfg) / main()
     Papel (enum)        -> Cliente | Conversor | Storage
     Config (struct)     -> amqp_url, fila_originais, exchange_convertidas,
                            fila_storage, pasta_entrada, pasta_saida, from_env()
     Servico (trait)     -> executar(&mut self) -> Result<u64>
     Cliente (struct)    -> cfg, canal, publicadas; novo(), executar(),
                            listar_imagens(), publicar(nome, bytes)
     Conversor (struct)  -> cfg, canal, processadas; novo(), executar(),
                            tratar(payload, tag)
     Storage (struct)    -> cfg, canal, salvas; novo(), executar(),
                            salvar(nome, bytes) -> Result<PathBuf>
     Mensagem (struct)   -> nome, bytes; escrever() -> Vec<u8>, ler(payload)
     Topologia (struct)  -> fila_originais, exchange_convertidas, fila_storage;
                            declarar(canal, papel), vincular(canal, fila, exchange)
     modulos             -> amqp (conectar, propriedades_persistentes,
                            prefetch_um), io_imagem (converter, extensao),
                            relatorio, erro
     crates externos     -> lapin::Channel, tokio, image 0.25, anyhow
   Dependências (setas tracejadas) e três notas:
     - ordem do tratar(): converter -> publish -> ack (at-least-once, sobrescreve
       o mesmo nome, não duplica arquivo);
     - declarar() por papel: durable=true, FANOUT, delivery_mode=PERSISTENT,
       ack manual;
     - payload sem dependência nova: 4 bytes big-endian com o tamanho do nome,
       nome UTF-8, bytes da imagem (evita serde/base64).
